# 🚀 Enterprise Content AI Prototype

Automating enterprise content workflows using a multi-agent AI pipeline.

## 🧠 Overview

This project demonstrates a multi-agent AI system designed to automate the complete lifecycle of enterprise content — from creation to analytics.

It shows how content workflows can be structured to improve consistency and reduce manual effort.

## ⚙️ Features

* ✍️ AI-powered content generation
* 🛡️ Brand and compliance review
* 👤 Human-in-the-loop approval
* 🌍 Content localization
* 📡 Multi-channel distribution (simulated)
* 📊 Engagement analytics dashboard
* 🔄 Fallback handling for API limits

## 🏗️ Architecture (Pipeline)

User Input
→ Draft Generation
→ Compliance Review
→ Human Approval
→ Localization
→ Distribution
→ Analytics

## 🛠️ Tech Stack

* Python
* Google Gemini API
* Google Colab
* Matplotlib

## ▶️ How to Run

1. Open the notebook in Google Colab
2. Add your Gemini API key in environment/secrets
3. Run all cells
4. Enter a content prompt when prompted

## 🎯 Problem Statement

Build an AI agent system that automates the full lifecycle of enterprise content — including creation, compliance review, localization, and multi-channel distribution. The goal is to improve turnaround time and maintain content consistency.

## 💡 Note

The system includes a simple fallback mechanism so the workflow can continue even if API limits are reached.
